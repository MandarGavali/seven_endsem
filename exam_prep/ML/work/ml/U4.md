### Definition
**Reinforcement Learning (RL)** is a type of machine learning in which an **agent** learns to take **actions** in an **environment** by **trial and error**, receiving **rewards or penalties**, so as to **maximise the cumulative (long-term) reward**. No labelled data is given – only a **reward signal**.

![Fig. Agent–environment interaction loop in RL](rl_loop){9}
- **Agent:** learner/decision maker (follows policy π).
- **Environment:** world the agent acts in.
- **Action aₜ:** move chosen by the agent. **State sₜ₊₁:** new situation returned by environment.
- **Reward rₜ₊₁:** numerical feedback (+ve = good, −ve = bad).

### 1. Elements of RL
- **Agent, Environment, State (s), Action (a), Reward (r)**.
- **Policy π(a|s):** strategy mapping states to actions.
- **Value function V(s):** expected long-term return from a state.
- **Q-value Q(s,a):** expected return of taking action a in state s.
- **Model (optional):** agent's prediction of environment's next state/reward.
- **Discount factor γ (0–1):** importance of future rewards.
$ Return Gₜ = rₜ₊₁ + γ rₜ₊₂ + γ² rₜ₊₃ + …

### 2. Need / Importance of RL
1. Learns **without labelled data** – only feedback from interaction.
2. Solves **sequential decision-making** problems where actions affect future states.
3. Handles **delayed rewards** (e.g., winning a game only at the end).
4. **Adapts** to dynamic, uncertain environments; continuous learning.
5. Balances **exploration vs exploitation** – discovers new strategies.
6. Achieves **super-human performance** (AlphaGo, Atari games) and real-world control.

### 3. Types of Reinforcement Learning
1. **Positive reinforcement:** a reward is given for good behaviour → increases frequency of that behaviour (maximises performance; too much may overload states).
2. **Negative reinforcement:** behaviour is strengthened by **removing/avoiding a negative condition** (e.g., penalty) → ensures minimum standard of performance.
- *By approach:*
  - **Model-based vs model-free** (Q-learning, SARSA are model-free).
  - **Value-based** (Q-learning, DQN), **policy-based** (REINFORCE), **actor–critic**.
  - **On-policy** (SARSA) vs **off-policy** (Q-learning).

### 4. Real-Time Applications
| Area | Application |
|---|---|
| Games | **AlphaGo**, chess, Atari – learn winning strategies |
| Robotics | Robot walking, grasping objects, industrial automation |
| Self-driving cars | Lane keeping, parking, trajectory planning |
| Finance | **Stock trading**, portfolio management |
| Healthcare | Dynamic treatment plans, drug dosage |
| Recommendation | News/video recommendations (YouTube, Netflix) |
| Resource management | Data-centre cooling (Google), traffic-light control |
| NLP / Chatbots | Dialogue systems, **RLHF** for large language models |

### Example
A dog learns tricks: it **sits** (action) after the command (state); gets a **biscuit** (reward); it learns to repeat the action. Similarly a robot learns to walk by getting +1 for each step forward and −10 for falling.

### Conclusion
RL lets an agent learn **optimal behaviour from rewards** through interaction; it is essential for sequential decision problems such as games, robotics and autonomous driving.
> **Memory trick – "A-E-S-A-R":** **A**gent in **E**nvironment sees **S**tate, takes **A**ction, gets **R**eward. Types: **+ve** adds a reward, **−ve** removes a penalty.

### Definition
- **Supervised learning:** learns a mapping from **labelled data** (input → known output) to predict outputs for new inputs.
- **Unsupervised learning:** finds hidden **patterns/structure** in **unlabelled** data.
- **Reinforcement learning:** an **agent learns by interaction**, using **rewards** to find the best actions.

![Fig. Three learning paradigms of machine learning](learning_types){13}

### 1. Supervised Learning
- Data: pairs (x, y) – a "teacher" provides correct answers.
- Tasks: **classification** (discrete y) and **regression** (continuous y).
- Algorithms: linear/logistic regression, KNN, SVM, decision trees, neural networks.
- **Example:** email **spam detection**; house-price prediction.
### 2. Unsupervised Learning
- Data: only x (no labels).
- Tasks: **clustering, association rules, dimensionality reduction**.
- Algorithms: K-Means, DBSCAN, hierarchical, PCA, Apriori.
- **Example:** **customer segmentation**; market-basket analysis.
### 3. Reinforcement Learning
- Data: generated by **agent–environment interaction**; feedback = reward.
- Tasks: **sequential decision making / control**.
- Algorithms: Q-learning, SARSA, DQN, policy gradient.
- **Example:** **game playing (AlphaGo)**, self-driving car, robot navigation.

### 4. Comparison
| Basis | Supervised | Unsupervised | Reinforcement |
|---|---|---|---|
| Input data | **Labelled** (x, y) | **Unlabelled** (x) | No fixed dataset; **states from environment** |
| Feedback | Direct – correct answer | **None** | **Reward / penalty** (delayed) |
| Goal | Predict output / label | Discover patterns, groups | **Maximise cumulative reward** |
| Learning style | Learn from teacher (examples) | Self-organisation | **Trial and error** |
| Tasks | Classification, regression | Clustering, association, dim. reduction | Control, decision making |
| Algorithms | LR, SVM, KNN, DT | K-Means, DBSCAN, PCA, Apriori | Q-learning, SARSA, DQN |
| Decision type | Independent, one-shot | – | **Sequential**, each action affects future |
| Evaluation | Accuracy, MSE | Silhouette, WCSS | Total reward |
| Example | Spam filter, price prediction | Customer segmentation | Chess/AlphaGo, robot walking |

### Conclusion
Supervised learning learns **from answers**, unsupervised learning **finds structure**, and reinforcement learning **learns from rewards** by acting in an environment.
> **Memory trick:** **S**upervised = **S**tudent with teacher; **U**nsupervised = **U**nguided explorer; **R**einforcement = **R**eward-driven pet.

### Definition
**Q-Learning** is a **model-free, off-policy, value-based** reinforcement learning algorithm that learns the **optimal action-value function Q*(s, a)** – the expected cumulative reward of taking action a in state s and acting optimally afterwards – using the **Bellman equation** and a **Q-table**.

### 1. Important Terms
- **State (s), Action (a), Reward (r), Next state (s′)**.
- **Q-value Q(s,a):** "quality" of action a in state s.
- **Q-table:** table with rows = states, columns = actions, entries = Q-values (initialised to 0).
- **Learning rate α (0–1):** how much new information overrides old.
- **Discount factor γ (0–1):** importance of future rewards.
- **Episode:** one run from start state to terminal state.
- **ε-greedy policy:** with probability ε **explore** (random action), else **exploit** (best Q action).
- **Temporal Difference (TD) error:** r + γ max Q(s′,a′) − Q(s,a).

### 2. Q-Learning Update Rule (Bellman)
$ Q(s, a) ← Q(s, a) + α [ r + γ · maxₐ′ Q(s′, a′) − Q(s, a) ]
- **r + γ max Q(s′,a′)** = target (TD target); difference from old Q = TD error.

### 3. Algorithm / How it works
![Fig. Q-Learning algorithm flowchart](qlearning){8}
1. **Initialise** Q(s, a) = 0 for all states and actions; set α, γ, ε.
2. For each **episode**: start at initial state s.
3. **Choose action a** using ε-greedy policy.
4. **Perform a**, observe reward **r** and next state **s′**.
5. **Update Q(s, a)** using the update rule.
6. Set **s ← s′**; repeat steps 3–6 until terminal state.
7. Repeat many episodes until Q-values **converge**; optimal policy **π*(s) = argmaxₐ Q(s, a)**.

### 4. Example (one update)
Robot in a grid: state **S1**, action **Right** → reaches **S2**, reward **r = +10**. Given α = 0.5, γ = 0.9, Q(S1,Right) = 0, max Q(S2,·) = 5:
$ Q(S1,Right) = 0 + 0.5 [10 + 0.9 × 5 − 0] = 0.5 × 14.5 = 7.25
| State | Left | Right | Up | Down |
|---|---|---|---|---|
| S1 | 0 | **7.25** | 0 | 0 |
| S2 | 0 | 5 | 0 | 0 |
Next time in S1, the agent prefers **Right** (highest Q).

### 5. Advantages / Disadvantages
- **+** Model-free (no environment model needed); off-policy (learns optimal policy while exploring); simple; guaranteed convergence with enough exploration.
- **−** Q-table becomes huge for large/continuous state spaces (→ **Deep Q-Network**); slow convergence; needs tuning of α, γ, ε.
### 6. Applications
- Game playing, robot navigation, traffic signal control, recommendation, trading bots.

### Conclusion
Q-learning fills a **Q-table** by repeatedly applying the **Bellman update** while exploring, and finally acts greedily on the learned Q-values.
> **Memory trick:** "**New Q = Old Q + α (Target − Old)**", Target = **r + γ·max next Q**. Off-policy = learns the **max**, even while acting ε-greedy.

### Definition
The **Markov property** states that the **future state depends only on the present state (and action), not on the past history**. A **Markov Decision Process (MDP)** is the mathematical framework of RL in which an agent makes decisions in states that satisfy the Markov property.
$ P(sₜ₊₁ | sₜ, aₜ) = P(sₜ₊₁ | s₁, a₁, …, sₜ, aₜ)
- "**The future is independent of the past given the present.**"

### 1. MDP Components – tuple (S, A, P, R, γ)
- **S:** finite set of **states**.
- **A:** set of **actions**.
- **P(s′ | s, a):** **transition probability** of reaching s′ from s by action a.
- **R(s, a):** **reward** received after taking action a in state s.
- **γ:** **discount factor** (0 ≤ γ ≤ 1).
- **Policy π(a | s):** what the agent does in each state; goal = find **optimal policy π*** maximising expected return.

![Fig. Simple MDP: states, actions, transition probabilities and rewards](mdp){10}
- **Circles:** states (Class, Study, Sleep, Pass). **Arrows:** actions/transitions with probability P and reward R.
- Next state depends only on the current state and chosen action → Markov property.

### 2. Working of an MDP
1. Agent observes state **sₜ**.
2. Chooses action **aₜ** by policy π.
3. Environment moves to **sₜ₊₁** with probability P(sₜ₊₁ | sₜ, aₜ) and gives reward **rₜ₊₁**.
4. Repeat; maximise expected return **Gₜ = Σ γᵏ rₜ₊ₖ₊₁**.
5. Solve using **Bellman equations** (value iteration, policy iteration, Q-learning).
$ V*(s) = maxₐ [ R(s, a) + γ Σₛ′ P(s′ | s, a) V*(s′) ]

### 3. Relation of Markov Property to RL & Why it is Important
1. **Foundation of RL:** RL problems are modelled as MDPs; the Markov property makes the state a **sufficient statistic** of history.
2. **Simplifies decision making:** the agent needs only the **current state** to choose the best action – no need to store full history.
3. **Enables Bellman equations / recursion:** value of a state can be written in terms of values of next states → basis of **dynamic programming, Q-learning, TD learning**.
4. **Reduces computation & memory** – policies and value functions are functions of state only.
5. **Guarantees convergence** of algorithms like value iteration and Q-learning (under conditions).
6. If the property does not hold (partial observation), we use **POMDPs** or add history (e.g., stacking frames) to make the state Markov.

### Example
**Chess:** the current board position contains all information needed for the next move – how the pieces arrived there does not matter → Markov. **Weather** with only today's state deciding tomorrow's is a Markov chain.

### Conclusion
MDP = (S, A, P, R, γ) is the framework of RL, and the **Markov property** (future depends only on present) makes it solvable with Bellman equations.
> **Memory trick:** MDP = "**SAP-R-γ**" (**S**tates, **A**ctions, **P**robabilities, **R**ewards, **γ**). Markov = "**Present is enough**".

### Definition
These terms form the mathematical base of reinforcement learning: a **Markov chain** adds probabilities to states, a **Markov Reward Process** adds rewards, an **MDP** adds actions, and **Bellman equations / Q-functions** compute the value of states and actions.

### 1. Markov Property
- The next state depends **only on the current state**, not on past states.
$ P(sₜ₊₁ | sₜ) = P(sₜ₊₁ | s₁, s₂, …, sₜ)
- Example: in Ludo/snake-ladder, next position depends only on present position and dice.

### 2. Markov Chain (Markov Process)
- A sequence of random states with the **Markov property**, defined by a tuple **(S, P)** – states and **transition probability matrix**.
- Each row of P sums to 1.
![Fig. Two-state weather Markov chain](markov_chain){7}
- **Example:** Sunny → Sunny 0.8, Sunny → Rainy 0.2; Rainy → Sunny 0.4, Rainy → Rainy 0.6.

### 3. Markov Reward Process (MRP)
- A Markov chain **with rewards**: tuple **(S, P, R, γ)**.
- **R(s)** = expected immediate reward in state s; **γ** = discount factor.
- Return: **Gₜ = rₜ₊₁ + γrₜ₊₂ + γ²rₜ₊₃ + …**; state value **V(s) = E[Gₜ | sₜ = s]**.
- **Example:** in the weather chain, reward +1 for Sunny, −1 for Rainy.

### 4. Bellman Equation
- Expresses the value of a state as **immediate reward + discounted value of next states** (recursive).
$ V(s) = R(s) + γ Σₛ′ P(s′ | s) V(s′)   (MRP)
$ Q(s, a) = R(s, a) + γ Σₛ′ P(s′ | s, a) maxₐ′ Q(s′, a′)   (Bellman optimality)
- Used by dynamic programming and Q-learning to compute optimal values.

### 5. Q-Table
- A **lookup table** with **rows = states, columns = actions**; each cell stores **Q(s, a)**.
- Initialised to 0 and updated during Q-learning; the agent picks the action with the **highest value** in its row.
| State | Up | Down | Left | Right |
|---|---|---|---|---|
| S1 | 0.2 | 0.0 | 0.1 | **0.8** |
| S2 | **0.6** | 0.3 | 0.0 | 0.1 |

### 6. Q-Function (Action-Value Function)
- **Q^π(s, a)** = expected cumulative discounted reward of taking action a in state s and then following policy π:
$ Q^π(s, a) = E_π [ Gₜ | sₜ = s, aₜ = a ]
- Optimal Q-function Q*(s,a) gives the optimal policy: **π*(s) = argmaxₐ Q*(s, a)**.
- Relation: **V(s) = maxₐ Q(s, a)** (for optimal values).

### Conclusion
Markov chain (S, P) → MRP (S, P, R, γ) → MDP (S, A, P, R, γ); the Bellman equation computes values recursively and the Q-function/Q-table stores the value of each action in each state.
> **Memory trick:** "**Chain → +Reward → +Action**" = MC → MRP → MDP. Q-table = "**cheat-sheet of best moves**".
