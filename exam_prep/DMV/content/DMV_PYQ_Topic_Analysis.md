# 6. Assumptions & Gaps

- **Unit mapping:** papers do not print unit names. Q1/Q2 = Unit 1, Q3/Q4 = Unit 2, Q5/Q6 = Unit 3, Q7/Q8 = Unit 4 (the standard SPPU 2019 end-sem pattern, which covers syllabus Units III-VI). Every question's topic matches the corresponding textbook chapter, which confirms this.
- **Short-note marks:** for "short note on (i) and (ii)", each sub-item is counted as one raw question with marks = total / number of parts required (e.g. 9 marks for two parts = 4.5 each; 2023 Q6b "any two of three" for 10 marks = 5 each).
- **Compound questions** were mapped to the topic that carries most of the marks: 2023 Q1a (graphics & computing + exploratory graphics) → 1.4; 2024 Q3a (FD + MDS) → 2.1; 2024 Q5b (cross tabulation & time series) → 3.4. The answers for those canonical questions cover the second part too.
- **2.1 / 2.3 / 2.11** are kept separate because they were asked as different questions (explain FD, explain MDS, differentiate). Together, FD/MDS appears in all 4 papers, so treat the pair as ★★★.
- **3.4 Time series** was asked in only 2 papers but at 9 marks both times, so it is ★★★ by the "repeatedly 8+" rule.
- **Materials:** the only DMV study material in the repo is `Textbooks/DMV Textbook.pdf` (TechKnowledge, Dr. Sujatha Rao, 96 pages, scanned). No separate lecture notes exist, so the textbook is the source for all citations. It was OCR'd; page numbers cited are **PDF page numbers**. Some OCR text is noisy, so diagrams and wording were checked against standard subject knowledge.
- "Asked in" years use the exam session year: 2023 = Nov-Dec 2023, 2024 = Nov-Dec 2024, 2025 = Nov-Dec 2025, 2026 = May-Jun 2026.
